Notes on building a Linux system from source by following the [Linux From Scratch book](https://www.linuxfromscratch.org/lfs/).

## Outline

1. Prepare the host system and the target partition
2. Download packages and patches
3. Build a cross toolchain and temporary tools
4. Enter chroot and build the base system software
5. Configure the system (boot scripts, network, fstab)
6. Build the kernel and set up the bootloader
